# Portfolio

Personal software development portfolio featuring project case studies, technical decisions and interactive demos.

[View portfolio](https://amahlenell.github.io/portfolio/)

## Projects

- [Narrow Path](https://narrow-path-recruiter-demo.vercel.app/demo) — shared progress and reflection app for couples.
- [Our Table](https://our-table-recruiter-demo.vercel.app/) — shared recipes, nutrition and meal planning.

Both demos use fictional data and run separately from production accounts. Cloud AI and provider operations are disabled in the demos. See [demo documentation](docs/DEMO_ACCESS.md) for details.

## Development

Built with HTML, CSS and JavaScript. Serve the repository root with a local static web server. No build step or package installation is required. GitHub Pages publishes the root directory.

The interface supports keyboard navigation, responsive layouts and reduced-motion preferences.
